# EZBI Analytics Deployment Guide\n\nThis directory contains all the necessary files and configurations for deploying EZBI Analytics to different environments.\n\n## 📁 Directory Structure\n\n```\ndeployment/\n├── docker-compose.yml          # Docker Compose for local development\n├── environments/               # Environment-specific configurations\n│   ├── .env.development\n│   ├── .env.staging\n│   └── .env.production\n├── kubernetes/                 # Kubernetes manifests\n│   ├── namespace.yaml\n│   ├── secrets.yaml\n│   ├── storage.yaml\n│   ├── database.yaml\n│   ├── backend.yaml\n│   ├── frontend.yaml\n│   ├── ml-engine.yaml\n│   ├── monitoring.yaml\n│   └── ingress.yaml\n├── monitoring/                 # Monitoring configurations\n│   ├── prometheus.yml\n│   └── alert.rules.yml\n├── nginx/                      # Nginx configuration\n│   └── nginx.conf\n├── scripts/                    # Deployment scripts\n│   ├── deploy.sh\n│   └── rollback.sh\n└── README.md                   # This file\n```\n\n## 🚀 Quick Start\n\n### Development Environment\n\n```bash\n# Start with Docker Compose\ndocker-compose up -d\n\n# Or use the deployment script\n./scripts/deploy.sh development\n```\n\n### Production Environment\n\n```bash\n# Deploy to production\n./scripts/deploy.sh production --verbose\n\n# Rollback if needed\n./scripts/rollback.sh production --steps 1\n```\n\n## 🐳 Docker Deployment\n\n### Prerequisites\n\n- Docker 20.10+\n- Docker Compose 2.0+\n- At least 8GB RAM\n- 20GB free disk space\n\n### Starting the Application\n\n```bash\n# Copy environment file\ncp environments/.env.development .env\n\n# Start all services\ndocker-compose up -d\n\n# Check status\ndocker-compose ps\n\n# View logs\ndocker-compose logs -f\n```\n\n### Services\n\n- **Frontend**: http://localhost:3000\n- **Backend API**: http://localhost:8000\n- **ML Engine**: http://localhost:8001\n- **Prometheus**: http://localhost:9090\n- **Grafana**: http://localhost:3001 (admin/admin)\n- **Database**: localhost:5432\n- **Redis**: localhost:6379\n\n## ☸️ Kubernetes Deployment\n\n### Prerequisites\n\n- Kubernetes 1.24+\n- kubectl configured\n- Helm 3.0+ (optional)\n- 16GB RAM cluster\n- 100GB storage\n\n### Deployment Steps\n\n1. **Create namespace and secrets:**\n```bash\nkubectl apply -f kubernetes/namespace.yaml\nkubectl apply -f kubernetes/secrets.yaml\n```\n\n2. **Deploy storage:**\n```bash\nkubectl apply -f kubernetes/storage.yaml\n```\n\n3. **Deploy database services:**\n```bash\nkubectl apply -f kubernetes/database.yaml\n```\n\n4. **Deploy application services:**\n```bash\nkubectl apply -f kubernetes/backend.yaml\nkubectl apply -f kubernetes/frontend.yaml\nkubectl apply -f kubernetes/ml-engine.yaml\n```\n\n5. **Deploy monitoring:**\n```bash\nkubectl apply -f kubernetes/monitoring.yaml\n```\n\n6. **Deploy ingress:**\n```bash\nkubectl apply -f kubernetes/ingress.yaml\n```\n\n### Scaling\n\n```bash\n# Scale backend\nkubectl scale deployment backend-deployment --replicas=5 -n ezbi-analytics\n\n# Scale ML engine\nkubectl scale deployment ml-engine-deployment --replicas=3 -n ezbi-analytics\n```\n\n## 📊 Monitoring\n\n### Prometheus\n\n- URL: http://prometheus.ezbi.example.com\n- Metrics collection from all services\n- Custom alerting rules\n- French hosting compliance\n\n### Grafana\n\n- URL: http://grafana.ezbi.example.com\n- Pre-configured dashboards\n- Alerting integration\n- Performance monitoring\n\n### Alerts\n\n- High CPU/Memory usage\n- Service downtime\n- Database connection issues\n- ML model performance degradation\n- Security incidents\n\n## 🔧 Configuration\n\n### Environment Variables\n\n#### Database\n- `DATABASE_URL`: PostgreSQL connection string\n- `DATABASE_HOST`: Database host\n- `DATABASE_PORT`: Database port\n- `DATABASE_NAME`: Database name\n- `DATABASE_USER`: Database user\n- `POSTGRES_PASSWORD`: Database password\n\n#### Redis\n- `REDIS_URL`: Redis connection string\n- `REDIS_HOST`: Redis host\n- `REDIS_PORT`: Redis port\n- `REDIS_PASSWORD`: Redis password\n\n#### Security\n- `SECRET_KEY`: Application secret key\n- `CORS_ORIGINS`: Allowed CORS origins\n- `SSL_ENABLED`: Enable SSL/TLS\n\n#### ML Engine\n- `ML_MODEL_PATH`: Path to ML models\n- `ML_INFERENCE_PORT`: ML inference port\n- `ML_CACHE_TTL`: Model cache TTL\n\n### Secrets Management\n\n```bash\n# Create secrets\nkubectl create secret generic ezbi-analytics-secrets \\\n  --from-literal=postgres-password=your-password \\\n  --from-literal=redis-password=your-password \\\n  --from-literal=secret-key=your-secret-key \\\n  -n ezbi-analytics\n\n# View secrets\nkubectl get secrets -n ezbi-analytics\n```\n\n## 🚀 CI/CD Pipeline\n\n### GitHub Actions\n\nThe CI/CD pipeline includes:\n\n1. **Security Scanning**\n   - Trivy vulnerability scanner\n   - Semgrep code analysis\n Deploy new version to \"green\" environment\n2. Run health checks\n3. Switch traffic to \"green\"\n4. Keep \"blue\" as backup\n5. Cleanup old \"blue\" after success\n\n### Commands\n\n```bash\n# Check current deployment\nkubectl get deployments -n ezbi-analytics -l color=blue\nkubectl get deployments -n ezbi-analytics -l color=green\n\n# Switch traffic\nkubectl patch service backend-service -n ezbi-analytics -p '{\"spec\":{\"selector\":{\"color\":\"green\"}}}'\n```\n\n## 🔐 Security\n\n### SSL/TLS Configuration\n\n```bash\n# Generate certificates (Let's Encrypt)\ncertbot certonly --webroot -w /var/www/certbot -d ezbi.example.com\n\n# Update certificates\nkubectl create secret tls ezbi-analytics-tls \\\n  --cert=fullchain.pem \\\n  --key=privkey.pem \\\n  -n ezbi-analytics\n```\n\n### Network Policies\n\n- Pod-to-pod communication restrictions\n- Ingress/egress traffic control\n- Database access limitations\n- Monitoring exceptions\n\n### RBAC\n\n```bash\n# Create service account\nkubectl create serviceaccount ezbi-analytics-sa -n ezbi-analytics\n\n# Bind role\nkubectl create rolebinding ezbi-analytics-binding \\\n  --role=ezbi-analytics-role \\\n  --serviceaccount=ezbi-analytics:ezbi-analytics-sa \\\n  -n ezbi-analytics\n```\n\n## 📈 Performance Optimization\n\n### Resource Limits\n\n```yaml\nresources:\n  requests:\n    memory: \"512Mi\"\n    cpu: \"250m\"\n  limits:\n    memory: \"1Gi\"\n    cpu: \"500m\"\n```\n\n### Horizontal Pod application caching\n- Nginx for static content\n- CDN for global distribution\n- Database query optimization\n\n## 🔍 Troubleshooting\n\n### Common Issues\n\n#### Database Connection Issues\n```bash\n# Check database pod\nkubectl get pods -n ezbi-analytics -l app=postgres\n\n# Check database logs\nkubectl logs -n ezbi-analytics deployment/postgres-deployment\n\n# Test connection\nkubectl exec -it deployment/postgres-deployment -n ezbi-analytics -- psql -U ezbi_user -d ezbi_analytics\n```\n\n#### ML Model Loading Issues\n```bash\n# Check ML engine logs\nkubectl logs -n ezbi-analytics deployment/ml-engine-deployment\n\n# Check model files\nkubectl exec -it deployment/ml-engine-deployment -n ezbi-analytics -- ls -la /app/models/\n```\n\n#### Performance Issues\n```bash\n# Check resource usage\nkubectl top pods -n ezbi-analytics\n\n# Check HPA status\nkubectl get hpa -n ezbi-analytics\n\n# Check metrics\nkubectl get --raw /metrics | grep ezbi\n```\n\n### Debugging Commands\n\n```bash\n# Get pod details\nkubectl describe pod <pod-name> -n ezbi-analytics\n\n# Check events\nkubectl get events -n ezbi-analytics --sort-by=.metadata.creationTimestamp\n\n# Port forwarding\nkubectl port-forward -n ezbi-analytics deployment/backend-deployment 8000:8000\n\n# Execute commands in pod\nkubectl exec -it deployment/backend-deployment -n ezbi-analytics -- /bin/bash\n```\n\n## 📋 Maintenance\n\n### Backup and Restore\n\n```bash\n# Database backup\nkubectl exec -n ezbi-analytics deployment/postgres-deployment -- pg_dump -U ezbi_user ezbi_analytics > backup.sql\n\n# Database restore\nkubectl exec -i -n ezbi-analytics deployment/postgres-deployment -- psql -U ezbi_user ezbi_analytics < backup.sql\n\n# Redis backup\nkubectl exec -n ezbi-analytics deployment/redis-deployment -- redis-cli BGSAVE\n```\n\n### Updates\n\n```bash\n# Update application\nkubectl set image deployment/backend-deployment backend=ezbi/backend:v1.1.0 -n ezbi-analytics\n\n# Check rollout status\nkubectl rollout status deployment/backend-deployment -n ezbi-analytics\n\n# Rollback if needed\nkubectl rollout undo deployment/backend-deployment -n ezbi-analytics\n```\n\n### Log Management\n\n```bash\n# View logs\nkubectl logs -f deployment/backend-deployment -n ezbi-analytics\n\n# Log aggregation\nkubectl logs --selector=app=backend -n ezbi-analytics --tail=100\n\n# Export logs\nkubectl logs deployment/backend-deployment -n ezbi-analytics --since=1h > backend-logs.txt\n```\n\n## 🌍 French Hosting Compliance\n\n### Data Residency\n- All data stored in EU (France)\n- GDPR compliance\n- Data retention policies\n- Privacy by design\n\n### Banking
